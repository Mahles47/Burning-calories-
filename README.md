# عدّاد العجز التراكمي (PWA)

## الملفات (كلها في جذر الريبو، بدون مجلدات)
index.html · manifest.json · service-worker.js · icon.svg · icon-192.png · icon-512.png · icon-maskable-512.png · apple-touch-icon.png

## الرفع
1. فك ضغط الـ zip على الهاتف، ثم في GitHub: Add file ← Upload files، واختر كل الملفات معاً (لا حاجة لمجلدات).
2. Settings ← Pages ← Branch: main و / (root) ← Save، وانتظر دقيقة.
3. افتح https://USERNAME.github.io/REPO/ في Chrome، واتركه نحو 10 ثوانٍ ثم أعد تحميل الصفحة مرة.
4. اضغط زرار «📲 تثبيت التطبيق» الذي يظهر في الأعلى، أو ⋮ ← تثبيت التطبيق.
5. للتشخيص: ⚙️ ← «فحص جاهزية التثبيت».
